🚀 Passo a Passo: Como Publicar o Projeto no GitHub e Colocar Online
​Este guia ensina como criar o repositório, subir os arquivos gerados e habilitar a visualização online do seu Painel Interativo de TI.
​📋 1. Reúna os Arquivos do Projeto
​Certifique-se de salvar os 5 arquivos gerados na mesma pasta no seu computador:
​README.md (Documentação principal)
​fluxo_atendimento_ti.html (Painel Interativo BPMN)
​documentacao_atendimento_ti.html (Manual em HTML/PDF)
​documentacao_atendimento_ti.tex (Fonte em LaTeX)
​post_linkedin_atendimento_ti.md (Texto de divulgação)
​🛠️ 2. Criar o Repositório no GitHub
​Acesse o GitHub e faça login na sua conta.
​No canto superior direito, clique no botão "+" e selecione "New repository" (Novo Repositório).
​Preencha as configurações do repositório:
​Repository name: painel-atendimento-ti (ou outro nome de sua preferência)
​Description: Painel Interativo e Mapeamento de Governança BPMN 2.0 para Atendimento de TI.
​Public / Private: Marque como Public (necessário para o GitHub Pages gratuito).
​Initialize this repository with: Mantenha as opções desmarcadas (não adicione README ou .gitignore por aqui, pois já temos esses arquivos).
​Clique no botão verde "Create repository".
​📤 3. Subir os Arquivos para o GitHub
​Você pode escolher o método mais fácil para você:
​Opção A: Pelo Navegador (Mais Rápido / Sem Instalações)
​Na página do repositório recém-criado, clique no link "uploading an existing file" (enviar um arquivo existente).
​Arraste todos os 5 arquivos da sua pasta local para a área marcada no navegador.
​No campo "Commit changes" no fim da página:
​Digite no título: feat: add initial project files and interactive panel
​Clique no botão verde "Commit changes".
